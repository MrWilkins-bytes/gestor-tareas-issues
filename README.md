# Gestor de Tareas
## Estructura de index.html

- `<!DOCTYPE html>` indica que se utiliza HTML5.
- `<html lang="es">` establece el idioma de la página.
- `<head>` contiene los metadatos y el título de la pestaña.
- `<body>` contiene el contenido visible.
- `<h1>` muestra el encabezado principal.
- `<ul>` y `<li>` permiten crear listas de tareas.
